GUIDE · 04

关于 / 帮助

了解工具用途、数据处理方式与安全边界。

01

工具用途

电诊明根据设备类型、现场现象、安全确认和测量值，生成辅助诊断、排查顺序与维修作业指导草案，帮助整理现场信息和交接记录。

02

安全注意事项

严格执行断电、验电、挂牌上锁及现场作业规程。出现冒烟、火花、焦糊味或其他危险迹象时，停止检修并按应急流程升级处置。任何诊断内容都需授权人员现场复核。

03

本地规则与联网 AI

本地规则：在浏览器本地运行，无需 API Key；适用于离线基础诊断。
联网 AI：通过本地服务转发到已配置的模型，结合检索资料生成结果；需要网络和服务端 API Key。密钥保留在服务端配置中，不放在网页代码里。

04

无法连接时

确认项目后端已启动并能访问服务地址。联网分析不可用时，页面会尽量回退至本地规则诊断；历史记录需要通过本地服务读取。

电诊明是辅助工具，不构成安全许可、专业检测或设备维修授权。
