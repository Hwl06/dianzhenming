# 项目文档导航

## 最终运行版

项目唯一保留的前端位于仓库根目录：SPA `index.html`、`styles.css`、`app.js`、`rules.js` 配合 `server.mjs` 提供本机工作台。双击 `启动电诊明.bat` 启动，后端端口为 8788。

## 方案档案

- `方案档案/v1.0.6-交付基线/`：交付版改进方案，记录当前服务、安全与运维能力的基线。
- `方案档案/v1.0.6-RAG增强/`：RAG 的实现方案，作为最终运行版知识检索功能的设计记录。
- `方案书/`：项目目标与产品介绍。

## 运行指南

- `运行指南/启动联网版.md`：联网模式的配置和启动说明。
- `运行指南/演示脚本.md`：演示流程。

## 前端

项目只保留根目录这一套 SPA 工作台，直接使用根目录的 `启动电诊明.bat` 启动。前端调用同目录后端，并沿用本项目的 `.env` 与 `data/`。
