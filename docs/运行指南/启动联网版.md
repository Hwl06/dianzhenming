# 联网版启动与 RAG 使用

## 首次准备

1. 安装 Node.js 18+ 和 npm。
2. 在 PowerShell 进入本目录，安装依赖并建本机资料索引：

```powershell
npm install
npm run export-rules
npm run build-rag
```

建库会优先下载 BGE 中文向量模型。模型源不可达时会自动用离线字符 n-gram 检索向量完成建库。索引在 `data/vectors/index.json`。

## 配置千帆 AI（可选）

运行 `start.ps1` 首次会创建本地 `.env`，编辑其中的 `QIANFAN_API_KEY`；也可以先复制 `.env.example` 为 `.env`。

RAG 本地检索无需 AI Key。未配置 Key 时，诊断来自本地规则，但安全条件满足的低风险诊断仍会展示参考资料。

## 启动与关闭

双击 `启动电诊明.bat` 打开本机工作台（8788）。停止时运行 `stop.ps1`。

## 更新资料和测试

将经过审核的 Markdown 文件放入 `knowledge/`，执行：

```powershell
npm run build-rag
npm run test-rag -- "变频器 E-OC"
npm run smoke
```

高危/未完成安全确认的诊断跳过 RAG 和联网模型，优先显示本地安全指引。
