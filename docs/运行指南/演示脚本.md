# 电诊明演示脚本（含本机 RAG）

## 开始前

- 双击 `启动电诊明.bat` 启动本机服务并打开工作台（8788）。
- 确认 `knowledge/seed.md`、`data/vectors/index.json` 存在。
- 无千帆 Key 时使用本地规则，但 RAG 检索和引用仍可展示。

## 演示顺序

1. 点击“电机三相不平衡”案例，展示本地规则判断与“参考依据”中的电机资料。
2. 点击“变频器加速过流”，展示 E-OC 对应片段引用。
3. 点击“配电柜焦糊冒烟（高危）”，展示立即停机指引；高危场景跳过 RAG，因此不显示参考依据。
4. 展示最近诊断记录在本机保存。

## 安全说明

RAG 引用是资料辅助，不替代现场规程或持证电工判断。高危和安全确认未完成时不走向量检索或联网 AI。
